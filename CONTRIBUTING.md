# Contributing

Submissions are welcome when a project has a concrete reason to be recommended for a **modern Spring Boot 4.x+ application**.

Good reasons for inclusion include:

* reducing operational complexity
* reducing unnecessary infrastructure
* simplifying development or testing
* improving maintainability
* making upgrades safer
* solving a common production problem particularly well
* supplying useful functionality that Spring Boot itself does not already cover sufficiently

Lightweight, simple, composable, local-first, and single-purpose tools are preferred where relevant, but these are preferences rather than strict requirements. There are no arbitrary minimum requirements for GitHub stars, project age, number of maintainers, or company backing. Projects should nevertheless be usable today and should not appear abandoned or obviously broken.

Spring Boot 4.x relevance should be clear where applicable. This is an editorial list, and inclusion is ultimately at the maintainer's discretion. The list intentionally does not include every alternative; absence from the list is not a negative judgment.

Please disclose whether you are the author, maintainer, employee, sponsor, or otherwise affiliated with the project. Self-submissions are welcome.

If you find this list useful, consider starring the repository. It helps more developers discover the project, but is never required for contributing or inclusion.
